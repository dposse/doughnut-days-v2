# doughnut-days-v2

Static landing page for Doughnut Days. No build step — plain HTML, CSS and images.

## Structure

```
index.html      the whole page
styles.css      all styles (tokens at the top of the file)
assets/         hero photo, cruller photo
```

## Local preview

Open `index.html` in a browser, or run any static server from this folder.

## Netlify

Publish directory: the repo root (or `site/` if you keep this nested).
Build command: none.
