DOUGHNUT DAYS · LANDING PAGE SPEC
STRUCTURE (all variants)
  1. Header: wordmark "@doughnut_days" left; nav right — Donut Maps, Blog, Contact Us, Instagram icon. Collapses to a hamburger below 768px.
  2. Hero: full-bleed decorative photo (felt sun, DD_hero image.jpeg). H1 "Doughnut Days", subhead "(and other things)".
  3. Intro paragraph.
  4. H2 "Supporting our local bakeries" + paragraph.
  5. H2 "Donut Maps" + paragraph + link to the maps page.
  6. Footer: page links list | contact us + Instagram icon.
TYPE + COLOR (from the 2026 brand guide)
  • Headings: typewriter-inspired face, always white text on an opaque black box. Text-box style, zine/collage feel.
  • Body: plain, highly readable sans. Do not set body copy in the typewriter face.
  • Doughnut base #fdc689 · frosting #fff200 · text #eb3c8e. Use as accents only — the page is black, white, and photography.
  • Hero photo must not carry meaning: decorative, alt="".
VOICE
  • Authentic, relatable, sarcastic — against the system, never against a donut.
  • Informant tone: what you can get, what it costs, how hard it was to get.
  • Archetype: Everyman / Jester. Copy is conversational, never markety.
DECISIONS ALREADY MADE
  • One "Donut Maps" page covers both Raleigh and D.C. Metro (was two pages on the old site).
  • Maps stay Google My Maps embeds.
  • About is not in the nav on this pass; landing page only in scope.
  • Every screen ships desktop + mobile.
STILL OPEN
  • Real copy for all three paragraphs.
  • Whether the blog lives on this domain or links out.
  • Which typewriter face (Special Elite is a stand-in here).
